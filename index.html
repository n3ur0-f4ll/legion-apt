Legion packages

This is the signed APT repository of Legion, a system based on Debian 13 (trixie). Legion uses it by itself: the legion-archive-keyring package adds the key and the source below, and updates come with the other system updates. The packages change how a system boots, so the repository is not meant for other Debian systems.
